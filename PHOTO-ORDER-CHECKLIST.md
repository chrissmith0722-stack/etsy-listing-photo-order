# Etsy listing photo order (digital downloads)

Etsy shows image 1 in search/browse. Order matters more than polish.

## Recommended order (10 slots)

| # | Image | Why |
|---|-------|-----|
| 1 | **Cover / hero** — product name + one benefit, high contrast | Search thumbnail; must read at postage-stamp size |
| 2 | **What's inside** — flat lay or grid of included files | Answers "what do I get?" |
| 3 | **Close-up of main template** — readable cells / sections | Proof it's real, not a stock mock |
| 4 | **Before → after or filled example** | Shows outcome |
| 5 | **How it works** — 3-step graphic (Download → Open → Customize) | Reduces "is this hard?" |
| 6 | **Device mock** (laptop/tablet) optional | Lifestyle; keep text still readable |
| 7 | **Bonus / included extras** | Reminder scripts, samples, etc. |
| 8 | **Size / format callouts** — PDF, XLSX, Google Sheet note | Sets expectations |
| 9 | **FAQ graphic** — refund, personal use, no Canva Pro needed, etc. | Cuts support tickets |
| 10 | **Soft brand / thank-you** | Optional; don't put critical info only here |

## Mobile-first rules

- Put the **benefit text in the top 60%** of image 1 (mobile crops bottom).
- Avoid tiny body copy; prefer 5–8 words on hero.
- Same aspect ratio across the set (Etsy prefers square or 4:5 consistently).
- No fake UI chrome that implies a different app.

## Conversion checklist (pre-publish)

- [ ] Image 1 readable at ~100px wide
- [ ] Image 2 lists every file in the zip
- [ ] At least one filled example (not blank template only)
- [ ] Format/compatibility stated in image 8 or description
- [ ] No copyrighted brand logos you don't own
- [ ] Filename order matches upload order (Etsy keeps upload sequence)
